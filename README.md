# หวยลุงแมว 🐱

แอปจดโพยหวยรัฐบาล (2 ตัวบน / 2 ตัวล่าง / 3 ตัวตรง-โต๊ด) สำหรับลุงแมวและป้าจิก ใช้งานบนเครื่องเดียว ข้อมูลเก็บในเครื่อง

## สำหรับลุง (ติดตั้งครั้งแรก)

1. ติดตั้ง **Node.js** (เลือกรุ่น LTS) จาก https://nodejs.org — กด Next ไปจนจบ
2. ดับเบิลคลิก **`1-install.bat`** รอจนขึ้นว่า DONE

## ใช้งานทุกวัน

- ดับเบิลคลิก **`2-open-app.bat`** → เบราว์เซอร์จะเปิดแอปให้เอง (http://localhost:5178)
- **ห้ามปิดหน้าต่างดำ** ระหว่างใช้งาน ปิดหน้าต่างดำ = ปิดโปรแกรม

## อัปเดตเป็นเวอร์ชันใหม่

- เอาไฟล์เวอร์ชันใหม่มาวางทับในโฟลเดอร์เดิม (**อย่าลบโฟลเดอร์ `data`**)
- ดับเบิลคลิก `2-open-app.bat` ตามปกติ — ถ้ามีไฟล์ใหม่ โปรแกรมจะติดตั้ง/อัปเดตให้เองก่อนเปิด (รอสักครู่)

## ข้อมูลอยู่ที่ไหน

- `data/db.json` — ข้อมูลทั้งหมด (งวด, โพย, ยอดอั้น, ผลรางวัล)
- `data/backups/` — สำรองอัตโนมัติทุก 3 ชั่วโมง (ตามเวลาเครื่อง) เก็บ 60 ไฟล์ล่าสุด
- จะย้ายเครื่อง / สำรองเอง ให้ copy โฟลเดอร์ `data` ไปทั้งโฟลเดอร์
- ตอนอัปเดตแอปเวอร์ชันใหม่ อย่าลบโฟลเดอร์ `data`

## สำหรับนักพัฒนา

```bash
npm install
npm run dev      # Vite (5173) + server (5178) พร้อม hot reload
npm run build    # build หน้าเว็บไปที่ dist/
npm start        # รัน server ที่ใช้ dist/ แล้วเปิดเบราว์เซอร์
npm test         # unit test ของ src/lib.js (vitest)
```

- `server/index.js` — Express: `GET/PUT /api/db` เก็บข้อมูลทั้งก้อนใน `data/db.json` (มีเลข version กันเขียนทับเมื่อเปิดหลายแท็บ)
- `src/lib.js` — logic การคำนวณ (ยอดอั้น, ตัดส่งเกินอั้น `allocateItems`, ยอดจ่าย/ผู้ถูกรางวัล, migration ข้อมูลเก่า) มีเทสต์ใน `src/lib.test.js`
- เปิดได้ทีละแท็บ: แท็บใหม่จะล็อกแท็บเก่า (BroadcastChannel + `inert`) กันข้อมูลทับกัน; `update()` คืน `false` เมื่อไม่รับการแก้ไข
- `server/needs-build.js` — ให้ `2-open-app.bat` รู้ว่าต้อง `npm install` / build ใหม่หลังอัปเดตหรือไม่
- `src/pages/` — หน้าซื้อเลข / ดูยอดรวม / งวดทั้งหมด
- เปลี่ยนพอร์ตได้ด้วยตัวแปร `LOTTO_PORT`
- `docs/handoff/` — เอกสาร QA / handoff สำหรับนักพัฒนา (ไม่ติดไปใน Download ZIP)
